# Canal Mandji - Plateforme de Réservation de Cinéma

Bienvenue sur le dépôt de **Canal Mandji**, la plateforme premium de réservation et de suivi de séances de cinéma pour les cinéphiles de Port-Gentil, Gabon.

## 🚀 Fonctionnalités Principales

- **Catalogue Dynamique :** Parcourez les films à l'affiche et les prochaines sorties.
- **Réservation Facile :** Choisissez votre séance, votre siège (Standard, VIP) et réservez en quelques clics.
- **Programme de la Semaine :** Un planning interactif mis à jour dynamiquement pour planifier vos sorties cinéma.
- **Bandes-annonces Intégrées :** Visionnez les trailers YouTube directement depuis l'application.
- **Tableau de Bord Administrateur :** Espace dédié pour la gestion des statistiques de vente, des séances et des tickets.
- **Multilingue :** Interface entièrement traduite en Français et en Anglais.
- **Design Premium :** Interface moderne, effets de verre (Glassmorphism) et accents rouge néon pour une expérience immersive.

## 🛠️ Technologies Utilisées

- **Frontend :** React (via Vite)
- **Styling :** Tailwind CSS
- **Animations :** Framer Motion
- **Icônes :** Lucide React
- **Gestion du Routage :** React Router
- **Internationalisation :** Contextes React personnalisés (i18n)

## 📦 Installation et Lancement Local

1. **Cloner le dépôt :**
   ```bash
   git clone https://github.com/Smeby33/canal-mandji-.git
   cd canal-mandji-
   ```

2. **Installer les dépendances :**
   ```bash
   npm install
   ```

3. **Lancer le serveur de développement :**
   ```bash
   npm run dev
   ```

L'application sera accessible localement, par défaut sur `http://localhost:5173`.

## 🎨 Aperçu du Design
Le design met en avant un thème sombre ("Dark Mode") profond avec des touches de rouge vif pour rappeler l'ambiance authentique des salles obscures, complété par des panneaux translucides et des micro-animations fluides.
